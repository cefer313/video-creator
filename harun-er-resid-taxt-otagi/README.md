# Harun ər-Rəşidin taxt otağı

İstifadəçinin öz otaq videosu (kitab rəfləri, masa, divan) süni intellektlə Abbasi xəlifəsi Harun ər-Rəşidin
taxt otağına çevrilib (bədii təsəvvür). Kamera hərəkəti — yavaş geri çəkilmə — orijinaldakı kimi qalıb.

- **Fayl:** `out/harun-er-resid-taxt-otagi.mp4`
- **Müddət / format:** 6,5 san · 1920×1080 (16:9) · 24 fps · H.264 · səssiz
- **Dəyişənlər:** rəflər → oyma, qızılı taxçalar və çıraqlar; divarlar → göy-firuzəyi-qızılı kaşı naxışları;
  pəncərə → məşrəbiyyə şəbəkəli tağ; divan → qırmızı-qızılı örtüklü taxt; masa → alçaq masa, meyvə, buxurdan;
  stullar → döşəkçələr; döşəmə → xalçalar; çilçıraq → mis fənər.
- **Model:** FLUX 3 Video Edit (Higgsfield), ~15 kredit.

## Yenidən render
1. `SOURCES.md`-dəki əmrlə klipi `clips/flux.mp4` kimi endir.
2. `bash assemble.sh`
