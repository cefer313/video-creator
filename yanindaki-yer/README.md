# Yanındakı yer

60 saniyəlik qısa 3D animasiya filmidir (bədii təsəvvür). Kəbənin önündə, günbatımında başlayır. İmam Mehdi (ə.f.)
ağ libasda, yaşıl əbada və yaşıl çalmada görünür, üzü bütün kadrlarda nurla örtülüdür. O, gün ərzində
insanlara səssizcə kömək edir: arabanı qaldırır, qapını açıq saxlayır, oturacaqda yer verir. Film duayla bitir.

- **Fayl:** `out/yanindaki-yer.mp4`
- **Müddət / format:** 60 san · 1080×1920 (9:16, Reels) · 24 fps · H.264 · −15 LUFS
- **Səhnələr:** 1) Kəbənin önündə, 2) Qəzəbli adam, 3) Cavabsız zəng, 4) Xəstəxana otağı, 5) Yanındakı yer,
  6) Yenidən izdihamın içində, 7) Dua
- **Altyazılar:** Inter şrifti; dialoqlar Azərbaycan dilində

## Yenidən render
1. `SOURCES.md`-dəki əmrlərlə klipləri `clips/` qovluğuna endir.
2. `bash assemble.sh` — musiqi/effekt səslərini (`synth_audio.py`) və altyazıları (`make_subs.py`) yaradır,
   sonra ffmpeg ilə birləşdirir.
