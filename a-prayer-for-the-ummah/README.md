# A Prayer for the Ummah

30 saniyəlik 3D animasiya (1920×1080, 24 fps). Bazarda üç gənc tacir yaşlı alıcını aldadır; kənarda dayanan İmam Mehdi
(üzü heç bir kadrda görünmür) bunu görür, kədərlənir və dua edir: **"Allahım, İslam ümmətini xilas elə."**
Səhnə bədii təsəvvürdür, tarixi rəvayət kimi təqdim edilmir.

- Hazır video: `out/a-prayer-for-the-ummah.mp4`
- Yenidən yığmaq: `SOURCES.md` → klipləri endir → `bash assemble.sh` (ffmpeg lazımdır)
